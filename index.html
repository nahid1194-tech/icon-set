Icon to SVG

Upload line icons. Gemini reads each image and writes editable stroke-based SVG code, then the app compares the result with the original and refines it automatically.

If every model of one key fails, the next key is used automatically. Google counts quota per project, not per key, so extra keys only add quota if they come from different Google projects.
